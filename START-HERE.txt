SMS МОСТ — v0.2

APK СОБРАН 2026-10-04 через GitHub Actions. Android-компиляция и lint прошли.
Подпись APK v2 и целостность файла проверены. Проверка на телефоне пока не выполнена.
Проверена логика номеров, ключей профилей, допуска к боту, длинных сообщений,
повторов; синтаксис Java, Python и XML. Это не заменяет сборку и тест на Xiaomi.

Что реализовано в коде
• Русское приложение с включением/остановкой пересылки.
• Получатель задаётся его Telegram ID. Если ID неизвестен, есть подключение по коду.
• Все новые входящие SMS → Telegram; номер, отправитель/сервис, текст и время.
• Зашифрованная очередь, повтор отправки, обработка ограничений Telegram.
• Добавление eSIM: сначала ты сам вводишь номер, потом QR-код.
• Номер привязывается к EID адаптера + ICCID скачанного профиля.
• Меню профилей, изменение номера и переключение через Telegram.
• Постоянное уведомление и автозапуск после загрузки Android.

Как получить APK
Вариант 1: Android Studio на компьютере — открой папку sms-bridge,
дождись установки Android SDK 35 и синхронизации, выбери сборку APK.
APK появится в app/build/outputs/apk/debug/app-debug.apk.

Вариант 2: отдельный GitHub-репозиторий с содержимым этой папки.
Открой Actions → Build Android APK → Run workflow.
Сборка без адаптера не требует токенов или дополнительных параметров.
После успешной сборки внизу запуска появится SMS-Most-APK.
Токен Telegram в репозиторий или в чат с помощником НЕ нужен: его вводят в приложении.

УДАЛЁННАЯ УСТАНОВКА eSIM
Нужен второй APK — защищённый LPA-компонент для адаптера. Обычный 9eSIM из магазина
этот интерфейс не предоставляет. В tools/build_companion.py написана его сборка
на базе открытого openeuicc-bridge и GatewayProvider с проверкой подписи приложения.
В workflow для этого нужно включить build_adapter и передать проверенный commit SHA
репозитория Laiteux/openeuicc-bridge. Пока его исходники не были полноценно скачаны
и проверены в этой среде, фиксированный commit не выбран. Это реальная незавершённая
часть сборки, а не гарантия работы удалённой установки.

Производитель публикует Community Key с описанием для V2. Допуск этой подписи именно
на твоём V0 пока не подтверждён. Если карта её не разрешает, потребуется другой
официально разрешённый путь управления. Root или сброс не предлагаются автоматически.
Нужна проверка, когда адаптер приедет. Сама пересылка SMS не зависит от этого компонента.

Первые действия на Xiaomi (v0.2)
1. Установить новый APK. Для перехода с первого debug APK понадобится удалить старый:
   у новой сборки постоянный личный ключ, у прежней был временный ключ GitHub runner.
   Удаление старого приложения удаляет его настройки и неотправленные SMS.
2. На главном экране ввести токен бота из @BotFather.
3. В поле Telegram ID ввести ID получателя SMS, а не владельца Android.
4. Нажать «Запустить бота» и выдать разрешения.
5. Получатель пишет боту /start в своём Telegram. Бот отвечает только указанному ID.
6. Указать номер SIM в настройках и проверить «Отправить тест в Telegram».
7. На Xiaomi: автозапуск разрешён, батарея «Без ограничений».

Если ID неизвестен, можно оставить поле пустым. Бот начнёт отвечать на /start
и попросит 8 цифр, показанных на Android. Получатель отправляет эти цифры боту.
Никаких ссылок и кнопки «Проверить подключение» на Android больше нет.
Пересылка SMS и работа бота теперь включаются раздельно: бот отвечает даже при
отказе в разрешении SMS, а SMS без разрешения не получает.

Если Telegram недоступен, причина видна на главном экране. Интернет на телефоне
сам по себе не доказывает доступ к api.telegram.org. Проверь VPN на Android,
если Telegram API не отвечает. Конфликт с другим процессом бота показан как ошибка 409.

Входящее SMS
На номер: +79991234567 — это введённый тобой номер, не определённый оператором.
Сервис/отправитель: берётся из SMS; неизвестным отправителям название не выдумывается.
Сопоставление номера при eSIM основано на активном профиле в момент получения.
SMS-протокол обычно не передаёт номер получателя приложению, поэтому задержанное
сообщение в момент смены профиля нельзя со стопроцентной уверенностью атрибутировать.
При неподтверждённом или устаревшем состоянии подпишем «Номер не определён».

Бот
/start или /menu — главное меню
/status — состояние телефона
/profiles — профили адаптера
/add — добавление: номер → QR → необязательный /pin → подтверждение
/cancel — отмена ввода

Ограничения
• Приложение не меняет номер в системных настройках Android или у оператора.
• С адаптера принимаются SMS активного профиля; все сохранённые номера одновременно
  в сети не находятся. Во время переключения приём/подпись могут быть временно недоступны.
• После перезапуска надо один раз разблокировать телефон. Принудительная остановка
  приложения в настройках Android блокирует автозапуск до следующего ручного открытия.
• Фоновую работу нельзя гарантировать до теста именно этой версии HyperOS/MIUI.
• При потере ответа Telegram после фактической доставки возможен дубликат; номер SMS #
  помогает его заметить. Exactly-once у Telegram sendMessage нет.
• История доставленных SMS хранится локально зашифрованной 7 дней.
• Ограничения Android на доступ к некоторым SMS-кодам не обходятся.
• APK из каждой новой чистой debug-сборки может иметь другой ключ подписи. Для обновлений
  с сохранением данных нужен постоянный личный ключ сборки; его нельзя заменять публичным
  ключом адаптера. Проверка Android Lint в CI может выявить дополнительные ошибки.
